<p>一条住宅 IP 干不干净，不是付款那一刻决定的，也不是测一次 ping 就能定论。它更像一条随时间展开的曲线：出厂时的历史记录、到手时的即时读数、头几天的使用痕迹、满月后的复用情况，各自说明不同的事。下面按时间轴把这件事铺开，从下单前一直排到第 30 天，每个节点给一个可执行的检查动作和判断口径。</p>

<h2>一、先定义"纯净"：四个能测的指标</h2>
<p>口语里的"纯净"混了四件事，分开看才有意义：地址属性是否真是住宅、是否进过公开黑名单、同一时刻有多少人在用、历史上有没有被滥用的痕迹。四项里任何一项不合格，都足以让体验变差。</p>
<h3>四个指标分别对应什么风险</h3>
<p>属性不真，意味着平台一眼能看出这是机房或转售地址；进过黑名单，意味着有些站点会直接拒绝；共享率高，意味着邻居的行为会算到你头上；历史滥用多，意味着这个地址在很多库里已经有一条负面记录。风险来源不同，处置方式也不同。</p>
<h3>先建一张自己的检查表</h3>
<p>不要凭感觉判断，把四项指标固化成表格，每次换线都填一遍。填过三五条之后，你会发现自己对"好地址"的手感，其实是这张表的副产品。</p>

<h2>二、下单前：公开库里能看到哪些线索</h2>
<p>这一步不需要买任何东西，只要有候选地址或服务商给的测试地址就能做。很多人跳过这步，结果买到的是别人用剩的段，问题在第一天就暴露。</p>
<h3>先看归属再谈价格</h3>
<p>把候选地址丢进 ipinfo.io 和 bgp.he.net，确认 ASN 归属是 Comcast、Verizon、AT&amp;T 这类消费级运营商，还是某某 hosting。同一家服务商可能同时卖机房段和住宅段，报价单上未必写清楚，自己查最稳。</p>
<h3>要求提供测试地址</h3>
<p>正规服务商一般能给出短期试用或测试地址。拿到后别只 ping 一下，按第一节的四项指标各查一遍，再决定是否下单。价格区间大致在每月 60 至 200 元（仅供参考），明显低于这个区间的"住宅独享"，多半在共享率上有水分。</p>

<h2>三、到手当天：二十分钟初筛流程</h2>
<img src="/tp.png" alt="住宅 IP 纯净度从下单到满月复检的时间线检查节点">
<p>拿到地址后的第一小时很关键，此时地址还没被你的使用痕迹覆盖，读数最接近"出厂状态"。建议按固定顺序走一遍，把结果存成截图。</p>
<h3>T+0：五项即时读数</h3>
<p>依次查：ipinfo 的城市与 org、AbuseIPDB 的举报数与置信度、Scamalytics 的风险分、<code>dig -x 地址</code> 的反向解析、以及/24 段的 org 分布。五项都是只读操作，不会给地址留下任何使用痕迹。</p>
<h3>T+30 分钟：跑一次真实访问</h3>
<p>用干净的浏览器配置登录目标平台，做两三次普通对话，记录是否出现验证、首字节时间和流式输出是否连续。这一步的意义是验证"能不能用"，不是验证"稳不稳"，别把结论下得太早。</p>

<h2>四、第 1 至第 3 天：地址是否被反复标记</h2>
<p>头三天是观察期。地址在这段时间开始承载你的行为，也会暴露它自己的问题：上游线路是否抖动、同段邻居是否在用脚本、平台是否对这个段有额外策略。</p>
<h3>每天固定时段复测一次</h3>
<p>建议早中晚各测一次，记录往返时延、丢包和验证弹窗次数。三天下来如果验证次数超过两次，或者晚高峰丢包持续高于 2%，说明这条线不适合长期挂着。</p>
<h3>看变化而不是看单点</h3>
<p>单次 300ms 不必紧张，连续三天同一时段都到 400ms 才叫问题。同样，AbuseIPDB 的举报数如果在三天内从 0 涨到 5 以上，说明同段有人在制造噪音，应该考虑换段。</p>

<h2>五、第 7 天与第 30 天：两次复检决定去留</h2>
<p>一周和一个月是两个自然的决策点。前者用来判断"能不能用下去"，后者用来判断"值不值得续费"。</p>
<h3>第 7 天：复检四项指标</h3>
<p>把第一节的表格再填一遍，重点看黑名单和共享率有没有恶化。地址本身不会变，但使用它的人会变，一周时间足够看出这个段是不是"高流动性"的。</p>
<h3>第 30 天：算一笔续费账</h3>
<p>把整月的验证次数、中断次数、平均时延列出来，与月费放在一起看。若月费 100 元出头、全月零中断，续费没有悬念；若每月要处理三五次异常、还要额外花时间排查，即便便宜也不划算。</p>

<h2>常见问答</h2>
<h3>风险分低就一定干净吗？</h3>
<p>答：不一定。第三方评分只反映它掌握的数据，覆盖面和更新频率都不一样。建议同时看两三家，并且以自己三天到一个月的实际使用记录为准，评分只是初筛。</p>
<h3>共享 IP 一定不能用吗？</h3>
<p>答：要看用途。只做普通浏览问题不大，涉及登录、订阅这类需要连续身份的动作时，共享带来的不确定性会明显放大。预算允许的话，关键账号尽量用独享。</p>
<h3>地址换了，账号要不要跟着换？</h3>
<p>答：不要在同一时间做两件事。换地址本身已经是一次变化，此时再改设备、改资料，会让排查失去参照。建议一次只动一个变量，观察几天再动下一个。</p>
<h3>多久复检一次比较合适？</h3>
<p>答：新地址头一周每天一次，稳定后每月一次即可。遇到平台改策略或线路明显变慢时，临时加一次复检，不必长期高频监控。</p>

<h2>合规提示</h2>
<p>本文所列查询工具与评分区间仅为方法示例，各平台数据口径不同，读数不能互相替代，也不构成对任何地址质量的保证。</p>
<p>请在遵守目标平台服务条款与所在地法律法规的前提下使用网络资源，查询与测试应限于自己有权使用的地址，不得用于扫描、探测他人网络。</p>
<p>文中价格区间为市场常见范围，仅供参考，实际以服务商报价为准；测试结论具有时效性，隔一段时间需重新核对。</p>
